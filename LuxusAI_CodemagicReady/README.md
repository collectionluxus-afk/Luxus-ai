# Luxus AI Android App — V4

This is an Android Studio project wrapping the Luxus AI V4 quotation system as a private single-device app.

## Included
- Luxus Collection logo as app icon
- V4 quotation UI and printable A4 layout
- Most-selling bag watermark built into the quotation
- Editable GST, rates, buyer details and terms
- Default terms: packing/transport extra, 50% advance / balance before dispatch, delivery as discussed
- Customer, follow-up and order/payment sections
- Local browser storage for drafts/data
- Native Android Print / Save PDF through the system print dialog

## Build
Open this folder in Android Studio, let Gradle sync, then Build > Build APK(s). The generated APK will be under app/build/outputs/apk/debug/.
